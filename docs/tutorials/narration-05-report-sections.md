# Narration script — "What Each Report Section Shows" (staff tutorial)

Video file: `report-sections.mp4` (80 seconds, silent, on-screen captions already burned in)

Play the video muted and read each line starting around its timestamp — match the caption
on screen more than the clock.

| ~Time | Say this |
|---|---|
| 0:02 | Here's what each section of a report actually shows. |
| 0:06 | We'll open Reports and pick one student, so every number below belongs to them. |
| 0:15 | Attendance: the percent of their scored periods marked present, with the trend against the period before. |
| 0:22 | STAR Percent: their overall average across Safety, Teamwork, Accountability, and Relationships. |
| 0:29 | Plan Thresholds: how many times one of their If/Then behavior plan conditions was met and a response delivered. |
| 0:38 | Trigger Time: the single day-and-period combination with the most infractions. Green means calm, red means hot. |
| 0:46 | Infractions: their total count, broken down by category — Attention, Social, Task, and Safety. |
| 0:54 | Incidents: how many Reminders versus full Resets were logged for them. |
| 0:59 | Level Up's: whether they're ready to move up a card color. |
| 1:04 | Frenzies: how many frenzy events were recorded for them in this timeframe. |
| 1:09 | That's the anatomy of a report — the same sections, just scoped to whoever or whatever group you've selected. |

## Notes on what's shown
- A pulsing orange ring circles whatever tile is being talked about, and a small dot tracks
  the real cursor throughout.
- Logged in as `staff25`, viewing a single student's report (see the earlier "Navigating
  Reports" video for how to switch between one student and a group).
- Every section here reads the same way for a group — the numbers are just totals or
  averages across everyone in that group instead of one student.
- All data is synthetic test data. No real students.
