## Notes on what's shown
- A pulsing orange ring circles whatever control is being talked about, and a small dot
  tracks the real cursor throughout.
- Logged in as `staff1`, an admin account — Add Staff/Outside Staff/Admin and Share login
  information are admin-only; a plain staff account only sees Add Student (also moved to
  the top of the list) and the search tables. Outside Staff can search and view every
  table but can't add or edit any account.
- Student email and parent/guardian email are both required fields now (marked with `*`)
  — the form won't save without them.
- The Add Student form is opened and filled to show what's required, then closed without
  saving, so the demo data stays put for re-recording.
- All data is synthetic test data. No real students.
