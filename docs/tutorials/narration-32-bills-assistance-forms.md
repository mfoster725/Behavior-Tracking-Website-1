## Notes on what's shown
- A pulsing orange ring circles whatever's being talked about, and a small dot tracks the
  real cursor throughout.
- Logged in as `staff17`, this student's real Case Manager, opening their Bills page — any
  staff member on a student's team can fill this out alongside them.
- The "correct" answers aren't a fixed key — they're computed from the student's own real
  data (their actual rent bill, take-home pay, grade, lunch number), so the same form graded
  differently for a different student, or the same student a different week.
- Sensitive real-world questions (citizenship, disability, criminal history, and similar)
  are shown grayed out as "Not collected in this class" rather than left off the form
  entirely — a deliberate privacy choice.
- The wrong-answer beat is deliberate: one field was submitted incorrectly on purpose so the
  red "Check this" outline and the "answers need fixing" banner would actually show up on
  screen, not just be described.
- All data is synthetic test data. No real students.
