Quick Actions

Import Users from CSV

Upload a .csv file to bulk-create user accounts.

CSV columns: User Number | Name | Role | Grades Taught | Case Manager

Role must be one of: Case Manager, Practitioner, Paraprofessional, Professional. Grades Taught is used for Case Managers (e.g. 7 for 7th only, 6-9 for 6th through 9th). Case Manager column is used for Paraprofessionals.

CSV columns: User Number (A) | Name (B) | District (C)

Username and password are generated the same way as staff (e.g. username from name, password username123). Users are added as Outside Staff.

CSV columns: Lunch Number | Initials | Grade | Card Color | Case Manager | Case Manager | Practitioner | Practitioner | Professional | Group Leader

Card Color: yellow, green, or blue. Team member columns are optional.
